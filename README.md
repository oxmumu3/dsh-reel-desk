# 制片台 (`@oxmumu3/dsh-reel-desk`)

给 DeepSeek Harness (`0.2.2-rc.1 || 0.2.2-rc.2 || 0.2.2-rc.3`) 用的产品发布片与科普短片工作台（Flow v3）。说一句想给哪个项目做片子，模型读完工作区先替你排好分镜单并在对话里直接摆出真实画面；你在面板里边看边改字、贴截图、拖取景、就地让模型写三个改法，满意后再导出 1080p MP4 或 README 用 GIF。

## 核心动线

打开左侧边栏的 **「制片台」**：

1. **开一条新片**
   - 首次打开（还没有自己的片子时）直接落在「开一条新片」，示例片与你自己的片子严格分开，绝不混在一起或覆盖已有片子。
   - 选好工作区、画幅（`横屏 16:9` / `竖屏 9:16`）与时长（`15 秒左右` / `30 秒左右`），点 **「交给 DeepSeek 排分镜」**。模型排完后，原生对话里直接出现带真实分镜画面的片子卡，点卡片即可回到制片台。
2. **放截图与取景（`真实界面特写`）**
   - 直接按 `⌘V` 粘贴剪贴板截图、拖拽本地图片，或从当前工作区导入图片（自动按内容哈希去重，仅允许工作区内路径）。
   - 在取景小图或左侧舞台上直接拖拽取景（`view = { x, y, z }`）、框重点（`focus`）、放光标（`cursor`）。重点框与光标绑定在原图坐标上，横竖屏切换时自动按重点重新对位。
3. **单镜就地改写与整片重排**
   - **单镜改法**：在检视栏「这一镜」下方直接输入想怎么改（如“口语一点”），不跳离面板即可生成 3 个实时渲染候选，点哪个换哪个。
   - **整片重排与并发防盖字**：在「整片」中点「去对话里说」会优先回到当初排这条片的原对话；改完后每镜可对比前后并单独退回。若你正在改同一镜：改不同字段自动合并；改同一字段摆出双方画面由你二选一，绝不静默盖掉你打的字。
4. **导出成片（MP4 / GIF · 正式 / 草稿）**
   - 支持 **正式（1080p · 60fps）** 与 **草稿（540p · 30fps）** 两种规格，以及 **MP4**（附静音音轨，兼容剪映、公众号、视频号）与 **GIF**（适合嵌入 GitHub README）两种格式。
   - 导出开始瞬间冻结分镜快照，合成期间可继续改分镜或随时取消（不留半截文件）；完成后支持页内 `<video>` 预览、在访达中显示、复制路径，若本机装有 `dsh-wechat` 则额外提供一键发到微信。

## 内置的 8 种镜头样式

| 镜头样式 | 适合拍什么 |
| :--- | :--- |
| **一句话输入** (`pain-input`) | 搜索框或输入框逐字打出真实用户痛点 |
| **真实界面特写** (`screen-shot`) | 真实产品截图入镜推近，支持原图坐标系取景、重点框与光标点击 |
| **数字漏斗** (`funnel-ticker`) | 2–4 级真实可核对数字滚动收束（无真实数字时默认禁用） |
| **模块咬合** (`lego-snap`) | 1–3 个模块卡片配合，支持「待补虚线 → 已跑通点亮」状态翻转 |
| **明暗双卡对比** (`dual-showcase`) | 浅色与深色双卡片视差对照 |
| **代码特写** (`code-diff`) | 旧做法对比 + 关键代码或命令逐行浮现 |
| **金句卡点** (`quote-kinetic`) | 1–4 张大字观点卡片按弹簧节拍逐行弹出 |
| **收尾号召** (`end-cta`) | 产品小图形（点 / 小签 / 插件块 / 不放）+ 行动引导按钮 |

## 环境与首次导出说明

- **支持系统**：目前仅支持 **macOS (`darwin`)**。
- **本机浏览器**：导出需要本机已安装 Google Chrome、Microsoft Edge、Brave 或 Chromium（或通过 `REEL_DESK_CHROME_EXECUTABLE` 指定路径）。若未找到浏览器，面板状态条会立即显示明确原因与下一步提示。
- **首次导出缓存**：安装包本身零第三方运行时依赖；首次导出时在 `${DSH_HOME || ~/.dsh}/reel-desk/runtime/` 自动安装并缓存 Remotion 4 组件（可通过 `REEL_DESK_RUNTIME_DIR` 覆盖）。
